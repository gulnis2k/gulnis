# Future Enhancements & Features

This document outlines planned functions and future additions to the Gul NiS Homey Cakes by SK platform.

## 1. Automated Order Management System
- Build a lightweight dashboard for tracking WhatsApp orders.
- Integrate WhatsApp Business API for automated order confirmation and status tracking messages.

## 2. Dynamic Categories in Sanity CMS
- Migrate the hardcoded categories array into Sanity CMS.
- Allow the bakery owner to dynamically add, edit, or remove product categories.

## 3. Advanced Cart & Checkout (Optional Future Phase)
- Implement a client-side shopping cart using React Context or Zustand.
- Allow users to add multiple items to a cart before generating a consolidated WhatsApp order message.
- Add an integrated payment gateway (e.g., Razorpay/Stripe) to capture advance payments online before redirecting to WhatsApp.

## 4. Reviews & Ratings System
- Create a Sanity CMS schema for customer reviews.
- Display dynamic product ratings on the frontend.

## 5. Multi-Language Support
- Provide multi-language toggles (e.g., English / Tamil) to cater to the local Coimbatore demographic.

## 6. Delivery Pincode Checker
- Add a widget on the product page where customers can enter their pincode to check delivery availability and estimated charges.
