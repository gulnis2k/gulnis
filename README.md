# Gul Nis Homey Cakes

A premium, modern, responsive, and SEO-friendly single-page bakery website.

## Tech Stack
- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS
- **CMS**: Sanity
- **Hosting**: Vercel

## Local Development
1. Clone the repository
2. Run `npm install`
3. Configure environment variables in `.env.local`
4. Run `npm run dev` to start the local development server at `http://localhost:3000`

## CMS Management
Content is managed via Sanity CMS. To edit products, open the Studio route and log in with your credentials. See `docs/CMS.md` for more details.

## Documentation
Please refer to the `docs/` folder for architectural decisions, SEO strategies, deployment details, and progress tracking.
